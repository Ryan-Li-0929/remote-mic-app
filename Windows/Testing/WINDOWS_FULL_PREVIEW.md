# Windows 完整版 Preview 验收

本清单仅用于独立分支 `codex/windows-full` 生成的 Windows Preview。它不会替换、
修改或重新打包 macOS 版。

## 自动门

1. Windows 3.12 全量单元测试通过，且日志中不存在 ResourceWarning。
2. PyInstaller 目录构建成功，`RemoteMicRC003.exe --dry-run` 返回 0。
3. Inno Setup 编译出安装器，安装器与便携包同时写入 SHA-256 清单。
4. 安装、覆盖升级、卸载均在临时 Windows 用户环境验证；用户配置与临时语音目录
   不会在覆盖升级时被误删。

## 真机门（Windows 11 + 小米蓝牙遥控器 2 Pro / RC003）

1. 配对后，连接页只能选中唯一一只 RC003；0 只或多只时失败关闭。
2. 逐个验证电源、方向、OK、返回、主页、菜单、音量加、音量减、TV：单击、双击、
   长按均只触发一次，不得串到其他按键。
3. 语音键使用自定义快捷键，而不是写死 Left Control；按住开始、松手停止。
4. 在按键页按住语音键并说话，右上角迷你音量条随遥控器真实 PCM 变化；拍电脑麦克风
   不应使该音量条变化。
5. 安装 VB-CABLE 后，应用输出选择 `CABLE Input`，语音输入软件选择
   `CABLE Output`；确认文字来自遥控器麦克风。
6. 开启“原始语音临时留存”后产生单声道 16 kHz WAV；关闭后不再产生新文件；结束
   4 小时后 WAV 与元数据自动删除；“全部删除”立即清空。
7. 睡眠/唤醒、蓝牙断开/重连、桥接重启各三次，无双重触发、卡住修饰键或残留收音。

## 发布边界

- GitHub Actions 只能证明软件构建、安装器编译与无硬件测试通过，不能替代上述真机门。
- 当前未签名 Preview 会触发 SmartScreen；公开发布前需完成应用签名。
- 返回/音量键若仍无法从 Windows 受支持输入路径取得，不得标记“完整版通过”；设备专用
  HID filter 必须先拿到目标 Windows 上的硬件实例/TLC 诊断，再完成 Microsoft 信任签名。
